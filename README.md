# MOMENTA

**Your life. Your moments. Your memories.**

MOMENTA — мобильное веб-приложение (PWA) для REC GENESIS HACKATHON, трек ArtTech, кейс «Make the Invisible Visible».
Вы пишете о дне, добавляете свои кадры и выбираете, каким он был: одно из шести настроений, у каждого — настоящая композиция.
Приложение собирает индивидуальное воспоминание **RE:LIVE** — вертикальную историю на 15–30 секунд.
Её цвет берётся из снимков, ритм — из реально звучащего трека, подача — из текста и настроения (**Emotion DNA**, **Soundtrack Sync**).
Всё работает локально, без внешних AI-сервисов. После первого запуска приложение открывается и офлайн.

## Запуск

Нужен Node.js 20+ (проверено на Node 26.13.1, npm 11.20).

```powershell
npm install
```

```powershell
npm run dev
```

Откройте http://localhost:5173. При первом запуске приложение само готовит три демо-дня и два события Countdown.
Создание дня — http://localhost:5173/create/relive: один экран без шагов (дата и название сверху, живая обложка, лента снимков, текст, настроение; «Своя музыка», «Голос», «Место и детали» раскрываются там же).

Продакшн-сборка с service worker:

```powershell
npm run build
```

```powershell
npm run preview
```

Тесты (71 проверка: детерминизм, названия, BPM, режиссура и контраст подписей, замена трека и обложки, настроение против темпа трека, каталог и декодирование шести MP3, выбор источника музыки, старые черновики, поиск, On This Day, Countdown, первый запуск в двух вкладках, обновление демо старых установок, единый владелец звука, обрыв ссылки, ритм по реально звучащей ссылке):

```powershell
npm test
```

Пересоздать демо-иллюстрации и иконки PWA (собственная векторная живопись → JPG/PNG через sharp):

```powershell
npm run assets
```

## Что внутри

| Раздел | Где |
|---|---|
| Emotion DNA, генератор сцен, названия | `src/engine/` (чистые функции, покрыты тестами) |
| Хранилище IndexedDB (Blob + метаданные, атомарное сохранение, миграции) | `src/services/db.ts` |

| Каталог настроений и треков (стабильные id) | `src/lib/catalog.ts`, `public/audio/`, подготовка — `scripts/prepare-audio.mjs` |
| Единый выбор источника музыки, звук плеера и предпрослушивание | `src/services/musicSource.ts`, `storyAudio.ts`, `previewSound.ts`, `audioOwner.ts` |
| Офлайн-аудио (кэш с перемоткой) | `src/services/offlineAudio.ts`, `vite.config.ts` |
| Редактор дня (создание и «Изменить») | `src/components/form/DayForm.tsx` и поля рядом |
| Плеер RE:LIVE и художественный слой | `src/components/relive/` |
| Экраны | `src/screens/` |
| Облачный контракт (P2): схема, RLS, Storage | `supabase/migrations/`, `.env.example` |
| Документы | `docs/DESIGN.md`, `docs/CREDITS.md`, `docs/VIDEO_SCRIPT.md`, `docs/TEST_REPORT.md` |

**Стек:** React 19, TypeScript 5.9, Vite 8, React Router 7, Tailwind CSS 4, Motion, Zustand, idb, Leaflet + OpenStreetMap, lucide-react, vite-plugin-pwa.

## Шесть настроений

| | Настроение | Композиция (Kevin MacLeod, CC BY 4.0) |
|---|---|---|
| 🌿 | Спокойствие | Meditation Impromptu 02 |
| ☀️ | Радость | Carefree |
| 🫶 | Нежность | Gymnopedie No. 1 (Erik Satie) |
| 🌧 | Ностальгия | Bittersweet |
| 🎉 | Драйв | Raving Energy (faster) |
| 🌌 | Мечтательность | Floating Cities |

Фрагменты по 36 с, громкость выровнена, мягкие вход и выход; источники и изменения — в `docs/CREDITS.md`.
Процедурного синтеза музыки больше нет: звучит либо композиция настроения, либо свой файл или прямая ссылка автора (у них приоритет).
Страница Spotify/YouTube открывается кнопкой «Открыть оригинал», а внутри MOMENTA честно звучит и называется трек настроения.
Если прямая ссылка недоступна или обрывается посреди истории, включается композиция настроения с той же позиции.
После первого запуска все шесть файлов докачиваются в кэш и играют офлайн, с перемоткой.

## Три демо-дня

| День | Настроение и трек | Что показывает |
|---|---|---|
| «Там, где дышат горы» | 🌿 Спокойствие · Meditation Impromptu 02 | 3 кадра, импрессионизм, летняя подборка и Share Again |
| «Ночь громче наших слов» | 🎉 Драйв · Raving Energy (faster) | геометрия Кандинского на долю, быстрые переходы, ночной концерт |
| «Дождь за тёплым стеклом» | 🫶 Нежность · Gymnopedie No. 1 | отражения и янтарные ореолы, камерный финал, «В этот день» (дата = сегодня год назад) |

Установки версии 1.1, где демо звучали синтезом в WAV, обновляются один раз в фоне: меняется только звук демо, правки автора, свой трек и удалённые демо остаются как есть.

## Данные и приватность

Все дни личные и хранятся только в IndexedDB этого браузера; настройки — в localStorage.
Share Again создаёт отдельную карточку PNG и не меняет сам день. Координаты и голос передаются только по отдельной галочке.
Облако не подключено: схема, правила доступа к строкам и файлам описаны в `supabase/migrations/0001_momenta_schema.sql`.
