# Отчёт о проверке MOMENTA

## Версия 1.2 — единый редактор, шесть настроений с настоящими треками, без синтеза

**Условия.** Windows 11, Node 26.13.1. Production-сборка (`npm run build` + `npm run preview`, порт 4173), встроенный Chromium-браузер Claude Desktop с эмуляцией 375×812, 390×844 и 1440×900. Профиль браузера остался от проверки версии 1.1 (демо со звуком синтеза, `demoSeeded = true`) — это проверка обновления на настоящей установке.
`npm test` — **71 проверка в 5 файлах, все проходят** (пять прогонов подряд); `tsc -b` — без ошибок; `npm run build` — успешно, прекеш PWA 85 файлов (≈ 2 МБ), аудио — отдельным кэшем.

**Как считался звук.** В браузере перехватывался `HTMLMediaElement.play` и считались элементы, которые не на паузе; громкость под голосом — по значениям, переданным в `GainNode`. **Это проверка сигнала и состояния плееров, а не прослушивание человеком**: на слух композиции и переходы не оценивались.
**Файлы каталога** проверены автоматически (`src/lib/catalog.test.ts`, mpg123): все шесть декодируются, 36 с, пики ниже 0,9 полной шкалы, есть звук; у «Драйва» энергия и плотность атак выше, чем у «Спокойствия». В приложении темп измерен по сигналу: Gymnopedie 76 BPM, Raving Energy 136 BPM, Carefree 96 BPM.

**Приёмка через интерфейс (production):**
1. **Обновление установки 1.1.** При первом открытии три демо перешли на композиции каталога: горы → Meditation Impromptu 02 (🌿), ночь → Raving Energy (🎉), дождь → Gymnopedie (🫶); id, названия и даты те же; старые WAV удалены из базы (0 аудиоблобов); два своих дня из 1.1 не тронуты (`updatedAt` прежний); `demoAudio = 2`. В кэше `momenta-audio` — шесть полных ответов 200 по 576 783 байт.

9. **Экраны.** 390×844: обложка ночного снимка сохраняет тени, кнопка «Собрать RE:LIVE» в пределах экрана, горизонтальной прокрутки нет (402 = 402 с полосой). 1440×900: поля слева (648 px), живая обложка справа (420 px), прокрутки по горизонтали нет.

**Найдено и исправлено при проверке:**
- Фокус к полю с ошибкой ставился через `requestAnimationFrame`, который не срабатывает в фоновой вкладке, — теперь `setTimeout`.
- При битой ссылке ритм считался по оценке для несуществующего трека — теперь ссылка измеряется, если сервер отдаёт файл, а недоступная заменяется в расчёте композицией настроения с предупреждением (`measureLink`, тест).
- Тест быстрых нажатий настроений иногда падал под нагрузкой: ожидание 400 мс впритык к затуханию 320 мс — дан запас.
- Подпись «Текст, фото и песня» на экране «Создать» → «Текст, фото и настроение»; под треком подборки добавлена атрибуция CC BY 4.0 (источник, лицензия, изменения).

**Не проверено в этой версии:** прослушивание человеком (громкость, переходы, кроссфейд на слух); прямая ссылка на чужой сервер без CORS (проверен тот же сервер и недоступный адрес); запись голоса с микрофона (панель блокирует устройства — проверен файл); системная `prefers-reduced-motion`; реальные iOS/Android. Анимации и View Transitions во время проверки шли в скрытой панели браузера, поэтому их длительность не оценивалась. В профиле браузера остался тестовый день «Вечер у тихого озера».

## Версия 1.1 — первые 15 секунд, режиссура, звук, первый запуск

**Условия.** Windows 11, Node 26.13.1. Production-сборка (`npm run build` + `npm run preview`), встроенный Chromium-браузер Claude Desktop с эмуляцией экрана 390×844 и 1440×900. Счётчики отрисовок и звука снимались в этом же настольном браузере (эмуляция телефона, не реальное устройство).
`npm test` — 50 проверок в 4 файлах, все проходят; `tsc -b` — без ошибок; `npm run build` — успешно, прекеш PWA 81 файл (≈ 2 МБ).

**Две воспроизведённые ошибки и регрессионные проверки** (`src/services/regression.test.ts`):
1. *Первый запуск в двух вкладках* создавал 6 демо-дней и 4 события (воспроизведено на исходной версии). Теперь у демо устойчивые id, запись «если ещё нет» в одной транзакции IndexedDB и межвкладочная блокировка. Тест: две параллельные подготовки → ровно 3 дня и 2 события; прерванный запуск дописывает недостающее и не трогает переименованный день; сборщик не удаляет файлы моложе часа.
2. *Предпрослушивание продолжало играть вместе с историей* (воспроизведено: два источника одновременно). Теперь у музыки один владелец, устаревшие асинхронные операции отменяются. Тесты падают на старом коде (`previewSound.ts` из HEAD — 2 падения; старое условие паузы в `storyAudio.ts` — 2 падения) и проходят на новом.

**Приёмка через интерфейс (production):**
- Две вкладки одновременно в чистом профиле → в базе `demo-mountains`, `demo-night`, `demo-rain`, `demo-event-baikal`, `demo-event-birthday`, 19 файлов без сирот. Прерванный запуск (перезагрузка после первого дня) → через 30 с ровно три дня; все три открываются со снимками и оригинальным треком.
- Архив → предпрослушивание (1 источник) → открыть тот же день (0) → Play (1) → Pause (0). Play→Pause→Play — 1; три нажатия в одном кадре — 1 (до исправления было 0: устаревший вызов гасил новый). Перемотка, «Оригинал / Арт» (звук идёт, +0,42 с, сцена та же), конец истории (тишина) → «Повторить показ» (1), уход вкладки в фон (0, кнопка «Воспроизвести»), выход (0). Быстрое предпрослушивание одного дня и открытие другого — 0 до Play.

Затем только обложка: свечение #BE9060 → #E0C49C (из лампы в левом верхнем углу), подпись слева → справа, худший контраст 4,50:1. Причины в «Почему такая атмосфера?» совпадают с применённым: переход 1,32 с, «136 BPM измерены по файлу».

## Найдено и исправлено при проверке

- Сообщение об ошибке названия оставалось после исправления — ошибки полей сделаны «живыми».
- Кнопки действий плеера не помещались в 390 px — переработана высота сцены и ряд кнопок.
- Карта перекрывала нижнюю панель — контейнер Leaflet изолирован (`isolate`); добавлен тайм-аут тайлов.
- Финал повторял средний кадр при двух фото — теперь возвращается к обложке.
- Подписи были слишком длинными и начинались с союзов — фразы режутся по смыслу.
- «до утра» давало «Утренний» — добавлено «полуночи»; распознаются имена («с Машей»).
- Тёмная палитра давала тусклое свечение — тон кадра осветляется, объяснение это указывает.
- После сохранения «Закрыть» вело в пустой мастер — теперь в архив.

## Что не проверено или ограничено

- **Запись с микрофона и «Текущее место»** — встроенная панель блокирует устройства. Проверены отказ и альтернатива (файл, пропуск, ручное место). Саму запись MediaRecorder нужно проверить на телефоне.
- **Нехватка места** — обработка `QuotaExceededError` (атомарная транзакция, понятное сообщение, черновик сохраняется) есть в коде, но не воспроизводилась.
- **Системное меню обмена** в панели недоступно (`navigator.canShare` нет). Проверен путь скачивания PNG.
- **Реальные устройства iOS и Android** не проверялись. Safari до 17 может не поддерживать отдельные эффекты Canvas (`soft-light`).
- **Офлайн-карта:** без сети показывается список мест. Тайлы кешируются только после просмотра онлайн.
- **Облако (P2)** — не реализовано. Есть миграция со схемой, RLS и правилами Storage, но она не развёрнута и не проверена под двумя аккаунтами. Кнопки общих альбомов неактивны и объясняют причину.
- Встроенные демо-треки — синтез MOMENTA. Анализ на реальных записях с плотным миксом может давать BPM ×2 или ×½; ручной BPM имеет приоритет.
